# Personal Portfolio Website

A simple personal portfolio website created using **HTML and CSS**.
This project is designed to showcase my basic web development skills and provide information about me and a way to contact me.

## 🌐 Pages

* **Home** – Introduction and basic information about me.
* **Contact** – Contact details and contact form.

## 🛠️ Technologies Used

* HTML5
* CSS3

## ✨ Features

* Simple and clean design
* Responsive layout
* Navigation between Home and Contact pages
* Basic styling using CSS
* Beginner-friendly portfolio project

## 📂 Project Structure

```text
portfolio/
│
├── index.html
├── contact.html
├── style.css
└── README.md
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
